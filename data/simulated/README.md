# Simulated study

Everything here is generated by `src/simulate_data.py` (seed 2453). It contains
no real respondents and no real model answers.

| File | Contents |
| --- | --- |
| `cleaned_CES_data.parquet` | 17,000 simulated respondents with the real cleaned file's 17 columns and storage types. Variables are linked (state, race, age, education and religion set a partisan lean that drives party ID, ideology, 2024 vote and 2026 intention), and survey weights up-weight young, non-college and Hispanic respondents. |
| `personas.parquet` | 100 weighted draws with replacement per 2026 Senate state, with `state` and `persona_row`. |
| `responses.parquet` | Simulated Jev, Mercury and Perplexity probabilities for each persona row on three run days. About 2% of rows are refusals, API errors or malformed vectors; these are marked invalid and their probabilities are null. |
| `forecast_state_draws.parquet` | 1,000 draws per model of each state's Democratic two-party share and winner. |
| `forecast_seat_draws.parquet` | 1,000 draws per model of Democratic, Republican and independent seats, including the 65 seats not up in 2026. |

Regenerate from the repository root with `uv run python src/simulate_data.py`.
Test it with
`uv run python -m unittest discover -s test -p 'test_simulated_*.py' -v`.
